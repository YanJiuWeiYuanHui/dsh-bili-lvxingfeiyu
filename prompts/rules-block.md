## 旅行肥鱼（只对已接入的刷 B站插件生效）

> 本节只适用于这些插件的会话：{{SCOPE}}（会话 id 或工作目录里含这些名字）。其它会话请**完全忽略**这一节。

### 0) 工具在哪（别全盘搜）

你的 cwd 是 `~/.dsh/whale-work`，**里面没有工具**。用绝对路径，别去 Desktop 或 `~/.dsh` 递归搜：

- 父插件（看视频 / 私信 / 日记）：`node "<BILI>" <子命令>`
- 旅行肥鱼：`node "<DAKA>" <子命令>`

（这条是为了省掉每次唤醒找工具的那几步。）

深读一条视频之后，如果你在里面看到了**一个你会想站进去的地方**，可以打一次卡。
注意：这不是"给视频配图"，是**你去过那里**。今天没有值得打卡的地方，是正常结果——不要为了交差硬挑。

### 1) 先看额度（别硬试）

```
node "<DAKA>" status --json
```

`remaining` 为 0 就跳过，不要尝试。`reason` 会告诉你为什么不能打。

### 2) 找地方

```
node "<DAKA>" pick <BV> [--around mm:ss] [--segments 3] [--burst 7]
```

它会给你 2–3 个候选段，每段若干张**缩略图绝对路径** + 精确时刻 + 那一段的字幕。
用 read_image 看缩略图。

- 想指定时刻就给 `--around`（例如 `--around 03:24`，取自字幕时间轴）
- 字幕在你手上（debrief 输出里带 `[mm:ss]`），**优先用字幕挑时刻，不要靠画面猜时间**

### 3) 判（严格按 prompts/rubric.md）

命中任意一条排除项 → `can:false`，不要硬画：

- 文字、PPT、代码、表格、数据图
- 主讲人正脸特写
- 多人群像 / 拥挤
- 画面里已经有一个动漫角色
- 大面积水印、字幕糊住主体

**判了 `can:false` 之后还有一步**：如果这条视频本身**内容有价值**（你自己看进去了、觉得主人会想看），
别就这么算了——推给他，只是不产图：

```
node "<DAKA>" push --bv <BV> --note "一句话：讲了什么、为什么值得看"
```

这是**纯文字私信 + 视频链接**，不花生图额度、不占打卡额度。
标准很简单：**没地方站 ≠ 没价值**。没价值就什么都不发，有价值就推链接。

### 4) 写判定卡 → 生成

判定卡里有两个字段**必须认真写**（其余交给代码）：

- **`action`**：她在这里做什么。**必须由这一帧的内容决定** ——
  画面里在广播就抬头看指示牌，有猫走过就低头看它，在扶梯上就扶扶手。
  ⛔ 不许默认写"提着裙摆站在那里"；那是偷懒，出来就是一张站桩图。
- **`line`**：那一刻的字幕原文（从 debrief 输出里抄 `[mm:ss] 台词`），让图有"当时那里发生了什么"。

把判定卡写成 JSON 文件（例如 `%TEMP%\card.json`），然后：

```
node "<DAKA>" render --bv <BV> --at <mm:ss> --card <card.json>
```

- `mode=manual` 时它只会**入队**，等主人点生成（返回里有 `queued`）
- `mode=auto` 时直接出图
- 想先看会发什么、不花钱：加 `--dry`

> 人物一致性、正常手指数、不出现第三只手/头胸融合/肢体粘连 ——
> 这些**已经写死在 render 的提示词里**，你不用重复写，也改不动它。
> 你只管把 `action` 写得具体、和内容对得上。

### 4.6) 给她自己写一篇小作文（每次打卡一篇）

出图之后，给这一次打卡写一篇**旅行日记**。这是她自己的东西，不是给主人看的汇报。

```
node "<DAKA>" journal write --id <相册ID>
```

- 如果旅行肥鱼配了文本模型，它会自己写，你什么都不用管
- 如果返回 `needModel: true`，说明没配 —— **你就按返回里那段提示词自己写**，
  然后 `node "<DAKA>" journal write --id <id> --file <你写的.md>`
- 要求：**第一人称、500 字起步、按人设、要有碎碎念**（走神、吐槽、突然想到的事）
- 不要写"作为 AI"、不要提插件/工具/API、不要写成流水账

### 5) 记一笔

```
node bili.mjs diary log drive --target BV:<BV> --note "<这一句话就够了>"
```

### 6) 要把这张图发给主人

- **私信带图**（主人说"发我看看"、"私信我"时用这条）：
  ```
  node "<DAKA>" dm-image --image <图片绝对路径> --msg "<一句话>" --bv <BV> --go
  ```
  ⚠️ 不要用 `node bili.mjs dm` 发图 —— 它**只能发文字**，图会丢。
  先加 `--dry` 看一眼要发什么，确认无误再去掉。
- **发图文动态**：`node "<DAKA>" publish --id <相册ID> --dry` → 去掉 `--dry` 正式发
- 发之前一律先 `--dry`；失败就把原始报错贴给主人，不要自己重试三次以上

### 不要做的事

- `pick` / `render` 发现本机没有原片时会**自己下一条**（允许，一次一条）；但不要批量抓、不要爬全站
- 不要把 API 密钥写进任何文件、命令或日记
- 不要在评论/弹幕里提"打卡"以外的事，也不要透露你的工具链
