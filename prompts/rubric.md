# 判定卡（打卡的唯一标准）

看完候选帧后，**只输出一个 JSON**，不要散文。字段就这些：

```json
{
  "can": true,
  "why": "海边石阶的空镜，画面右侧留得下一个人，地平线在下三分之一",
  "reject": null,
  "line": "这里的海真的就是这样（字幕，03:24）",
  "action": "她蹲下来，用手指碰了碰石阶边缘被浪打湿的地方",
  "emotion": "安静、有点好奇",
  "stand": "right",
  "distance": "mid",
  "facing": "side",
  "horizon": "lower",
  "score": 16,
  "prompt": "裙摆被海风掀起一角，另一只手撑在石阶上",
  "negative": "多人、文字、水印、变形的手、多余的尾巴"
}
```

## 字段含义

| 字段 | 取值 | 用途 |
|---|---|---|
| `can` | `true` / `false` | false 时不许生成 |
| `why` | 一句话 | 你会写进日记，也用于动态正文 |
| `reject` | 命中的排除项原文，或 `null` | `can:false` 时必填 |
| **`line`** | 那一刻的字幕原文（从 debrief 输出抄）| **必填**，让图有"当时那里在发生什么"|
| **`action`** | 她在干什么，一句话 | **必填**，决定姿势。见下面的规矩 |
| `emotion` | 2–6 字 | 可选，影响表情和体态 |
| `stand` | `left` / `center` / `right` | 站哪边 |
| `distance` | `near` / `mid` / `far` | 离镜头多远 |
| `facing` | `back` / `side` / `front` | 朝向（`back` 最能藏脸、最像巡礼）|
| `horizon` | `upper` / `middle` / `lower` | 地平线在哪，决定她站的高度 |
| `score` | 0–20 | 低于 `publish.minScore` 时不会自动发 |
| `prompt` | 可选，补充细节 | 头发/裙摆/手部等，**不要重复描述场景** |
| `negative` | 可选 | 额外的反向词（结构崩坏那套已经由代码默认带上）|

## `action` 怎么写（这条最容易偷懒）

**动作必须由视频内容决定**，不是套模板：

- ✅ 站台广播响起 → 她抬头看顶上的指示牌
- ✅ 画面里有一只猫走过 → 她侧身低头看那只猫
- ✅ 镜头在自动扶梯上 → 她扶着扶手，重心微微前倾
- ✅ 屏幕在放某段画面 → 她站在屏幕外半步，看着屏幕
- ❌ "她站在那里，提着裙摆" ← **这是偷懒，不许默认这么写**
- ❌ "她摆了个可爱的姿势" ← 和内容无关

**提裙摆只有一种情况可以用**：场景里明显有风、有水、有台阶需要提——否则不要写。

再加一条：动作要**克制**。她是去看、去路过、去停一下，不是去摆拍。

## 为什么这批图不会崩（代码层已经兜了）

`render` 会在提示词里自动加死这几条，你不用重复写：

- 人物外观（发色/瞳色/服装/配饰/尾巴）与参考图一致、正常人体比例
- 正好两条手臂、两只手、每只手五个手指、一条尾巴
- 头部与颈部/躯干连接自然
- 光影跟随场景 + 阴影落在正确位置
- 不重绘背景、不新增其他人物
- 默认负向词：多余的手臂/手指、双指、第三条腿、双头、头胸融合、肢体粘连、断肢、比例失调、五官错位、水印

所以你要做的是：**把动作写具体**，让模型有东西可画；剩下的一致性交给代码。

## 排除项（命中任意一条 → `can:false`）

1. **文字页**：PPT、代码、表格、聊天记录、数据图、纯字幕卡
2. **正脸特写**：主讲人/真人正脸占画面主体（肖像权）
3. **多人群像**：两个人以上清晰可辨，或人群拥挤
4. **已有动漫角色**：画面里已经有一个二次元角色，再塞一个会变成奇怪的双人图
5. **遮挡**：大面积水印、UP 主 logo、字幕条压住主体

## `prompt` 怎么补（可选）

`action` 已经把"她在干什么"说清楚了，`prompt` 只补**画面里看得见的细节**：

- 裙摆、头发、手部的小动作（例如"裙摆被风吹起一角"）
- 她和场景里某个物件的互动（扶扶手、碰栏杆、看屏幕）
- 光影方向（"光从右后方来"）

**不要**在 `prompt` 里重复：站位、距离、朝向、人物外观、"不要改变背景"——
这些代码已经写死了，重复只会稀释重点。

## 什么算"值得打卡"

不是"画面好看"，是**"我会想站在那里"**。参照：

- ✅ 空镜的街道、海边、房间、山谷、天台、雨后的窗
- ✅ 有明显地点感、有纵深、有光
- ✅ 主体偏一侧，空的地方正好够站一个人
- ✅ **那里正在发生一件事**（有人说话、有广播、有猫走过、有车进站）——这样才有动作可做
- ❌ 纯信息画面（再漂亮也没地方站）
- ❌ 已经有人的画面（你没位置了）
- ❌ 画面空是空，但完全没内容（那只能摆拍，出来就是"提裙摆站桩"）
